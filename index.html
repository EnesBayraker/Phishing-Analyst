Analyze suspicious links before you trust them.

Phishing Analyst helps users review suspicious URLs and message content directly in the browser. It gives awareness-based risk feedback without visiting links or sending user data to a server.

Core tools

Analysis workspace

The main analysis tools will be placed here. Each tool will guide the user with clear input validation, risk explanations, and safe next-step recommendations.

🔗 Interactive

URL Analysis

Enter a suspicious URL to check whether it matches common phishing patterns. The app will not visit the URL or send it to any server.

Tip: You can paste a full URL or a domain-like link. Do not click suspicious links before checking them.

✉️ Interactive

Message Analysis

Paste a suspicious message or email text to check whether it contains common social engineering signals. The text is analyzed only in your browser.

Tip: Paste only the suspicious text. Do not open attachments or click links inside suspicious messages.

Analysis History

Security Disclaimer

Phishing Analyst is an educational awareness project. It cannot guarantee that a URL or message is safe or malicious. Always verify suspicious links through official sources and avoid clicking unknown links.

Built with HTML5, CSS3, JavaScript, and Vite. No backend. No database. No authentication.
